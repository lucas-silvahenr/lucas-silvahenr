## 🚀 Featured Projects

### 💪 [Gym API](https://github.com/lucas-silvahenr/gym_api)

REST API for workout and exercise management with authentication and session tracking.

* **Tech Stack:** Python, FastAPI, SQLAlchemy, PostgreSQL, Docker, Pytest
* **Features:** JWT authentication, workout management, exercise library, RESTful API, automated testing, and CI/CD pipeline.

### 🖥️ [Gym Frontend](https://github.com/lucas-silvahenr/gym_frontend)

Frontend application for managing workouts through an intuitive and responsive interface.

* **Tech Stack:** React, JavaScript, React Router, Axios, Vite
* **Features:** User authentication, workout creation, exercise management, protected routes, and API integration.

### 📊 [Sales Report Automation](https://github.com/lucas-silvahenr/sales-report-automation)

Automation tool that consolidates sales spreadsheets received by email into a single report.

* **Tech Stack:** Python, Pandas, IMAP Tools, XlsxWriter
* **Features:** Email filtering, attachment processing, Excel report generation, and automated data consolidation.
